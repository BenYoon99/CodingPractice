1. 실행 환경 (Runtime)

" 어디서 돌아가는가?"

Java: JVM (Java Virtual Machine) 위에서 실행된다.
운영체제와 상관없이 JVM만 있으면 어디서든 
독립적으로 돌아가는 중량급 엔진이다.

TypeScript : JavaScript로 변환되어 실행된다.
웹 브라우저나 Node.js 환경에서 돌아가며
, 태생적으로 **웹**에 최적화된 경량급 엔진이다.


2. 타입체크의 엄격함 (Type Checking)

" 얼마나 깐깐한가?"

Java: 강력한 정적 타입의 언어다.
예를 들어 int로 한번 선언을 했으면
죽어도 숫자로만 써야 합니다.
타입 규칙을 어기면 컴파일 자체가 안 되는
철벽 보안입니다.

TypeScript: 점진적 타입 시스템이다.
자바 스크립트와의 호환성을 위해 타입을 느슨하게 잡을 수도 있고 (any) , 자바스크립트로 변환되고 나면 타입 정보가 사라집니다.
즉, 개발할 때는 깐깐하지만 실행할 때는 유연합니다.

3. 동시성 처리 방식 

Java 멀티 스레드

멀티 스레드 방식이라 다수의 CPU에 연결이
가능하기에
다수의 CPU에 연결하여 업무처리가가능해서
속도가 원활히 빠르다.
CPU는 Que 구조로 하나하나씩 업무처리를하기에
다수의 CPU란 다수의 줄인것이기에
분산된 일처리가 가능하기에
속도가 빨라지는것

EX) 2개의 CPU를 받는다면
한번에 2개의 작업을 빼는것이기에 속도가 빠름
GPU는 그냥 받아와서 한번에 
처리하는 방식 

TypeScript 싱글 스레드

한 번에 하나의 작업만 처리하는 싱글 스레드 기반(이벤트 루프)입니다.
대신 비동기 처리에 최적화되어 있어

4 Compiler vs Transpile

" 어떻게 변하는가?"

Java(Compiler) : 소스 코드 ( .Java)를 컴퓨터가 
이해하기 쉬운 "바이트코드(. class)**로 완전히 바꿉니다.

TypeScript(Transpile) : 소스 코드(.ts)를 실행 가능한 자바스크립트로 번역합니다. 즉,TS는 JS라는 옷을 입고 실행되는 셈이다.
