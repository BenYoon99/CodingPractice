import java.util.*;
import java.lang.*;
import java.io.*;

/*🔱 Mission: "상속받은 챔피언의 무결성을 증명하라"
상황: 롤(LoL) 챔피언 시스템을 설계합니다. 모든 챔피언은 '이름'이 있어야 하며, 특정 챔피언(자식)은 자신만의 '궁극기' 정보가 추가로 필요합니다.

조건:

부모 클래스 Champion:

String name 필드를 가집니다.

이름을 인자로 받는 생성자를 만드세요. (이름 없이는 태어날 수 없는 '무결성' 원칙 적용)

자식 클래스 Garen:

String ult (궁극기 이름) 필드를 추가로 가집니다.

생성자에서 name과 ult 두 가지를 인자로 받으세요.

핵심: super()를 사용하여 부모의 name 문신(초기화)을 먼저 해결한 뒤, 자신의 ult를 this로 세팅하세요.

실전 확인:

Main 클래스에서 Garen 인스턴스를 생성하고(new), 이름과 궁극기가 제대로 출력되는지 확인하세요.*/

class Champion {
    String name;
        Champion(String name){
            this.name=name;
            
        }
}
class Garen extends Champion {
    String ult;

        Garen(String name,String ult){
            super(name);
            this.ult=ult;
        }
}
class Main {
    public static void main(String[] args) {
        Champion garen = new Garen("가렌","데마시아");
        System.out.println(((Garen)garen).ult);
        System.out.println(garen.name);
    }
}
