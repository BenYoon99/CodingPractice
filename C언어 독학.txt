서식 지정자 ( Format Specifier)

%d  decimal (정수)  int 출력시 사용한다 

%f   float (실수) float double 출력시 사용한다

%c character (문자 하나 ) char  출력시 사용한다

%s String (문자열) String 클래스와같이 글자 여려개 출력시 사용한다 

%p Pointer  (메모리 주소다) 변수가 실제 메모리어디에 있는지 출력 

여기서
("사냥꾼의 체중은:? %d\n"  , 변수명);

이런식으로 내가 출력할 변수명의 타입을 맞춰
구멍을 열어주는것이다
내 변수명의 타입은 
해당 구멍과 타입이 일치할시 해당 구멍에 
출력된다.

자바의 scanner 

C의 scanf



scanf의 형식 

(서식지정자 , 앰퍼샌드 변수명);


서식지정자 %d %f

&변수명 


제미나이 제작 코드 

#include <stdio.h>

int main() {
    int weight; // 값을 담을 빈 그릇 준비

    printf("현재 몸무게를 입력하세요: ");
    
    // 정수(%d)를 입력받아 weight의 주소(&)에 저장하라!
    scanf("%d", &weight); 

    printf("입력하신 몸무게는 %dkg입니다.\n", weight);

    return 0;
}
