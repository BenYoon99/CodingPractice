[문제 조건]

Account 클래스를 만드십시오.

Getter/Setter를 만드십시오.

검문소: setBalance에서 들어온 값이 현재 잔액(this.balance)보다 작으면 

"에러: 잔액이 부족합니다."를 출력하고 값을 변경하지 마십시오.

참고: 여기서는 Setter를 '새로운 잔액을 설정하는 용도'로 사용합니다.

Main 클래스에서:

처음 잔액을 10000으로 설정하십시오.

setBalance(5000)으로 변경 시도 (성공해야 함).

setBalance(20000)으로 변경 시도 (에러 메시지 출력되어야 함).*/

class Account {
    private int balance;

}
    Account(int balance){
        this.balance=balance;
    }
    public getBalance(){
        return this.balance;
    }
    public setBalance(int balance){
        if(balance<this.balance){
            System.out.println("에러: 잔액이 부족합니다");
        }
        else{
            this.balance=balance;
        }

        
        
    }
