/*🔱 실습 4: 스마트폰 시스템 설계 (Final Boss)
[요구 사항]

**추상 클래스 Player**를 만드세요.

필드: String name;

추상 메소드: abstract void play();

**인터페이스 Internet**을 만드세요.

추상 메소드: void connect();

**클래스 SmartPhone**을 만드세요.

Player를 상속받고, Internet을 구현합니다.

play() 구현: "음악을 재생합니다." 출력.

connect() 구현: "5G 네트워크에 연결되었습니다." 출력.

Main 클래스에서 다음 로직을 완성하세요.

SmartPhone 객체를 생성하고 이름을 "Galaxy"로 저장하세요.

[핵심 미션] if문을 사용하여 "객체의 이름이 'Galaxy'이고, 동시에 이 객체가 Internet 기능을 가졌는지(instanceof)" 확인하세요.

조건이 참이라면 play()와 connect()를 호출하세요*/

abstract class Player {
    String name;

    public abstract void play();
}
interface Internet {

    public void connect();
}
class SmartPhone extends Player implements Internet{
    @Override

    public void play(){
        System.out.println("음악을 재생합니다");
    }
        @Override
        
    public void connect(){
        System.out.println("5G 네트워크에 연결되었습니다");
    }
    
}

class Main {
    public static void main(String[] args) {
        Player g = new SmartPhone();
        g.name = "Galaxy";
        
        if(g.name.equals("Galaxy") && g instanceof Internet){
            g.play();
            ((SmartPhone)g).connect();
            
            
        }
    }
}
