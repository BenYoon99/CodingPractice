1. 변수 쉐도잉과 하이딩의 차이




1-1 변수쉐도잉


변수 쉐도잉이란 

필드 변수값 



지역 변수값이 있다면

해당 메소드내부에서는

그 해당 이름을 호출시

지역변수값이 우선도를 갖는걸 말함

생성자를 예시로들면

String name; 이라는 필드 변수가 
존재해도

생성자에서 

Person(String name){

이 내부에서의 name은 

같은  name이지만 지역변수/매개변수/파라미터 name 가 된다.
고로  이렇게 
가장 가까운놈이 자기를 가린다고 이해하면된다.
여기서 필변 name을 부르려면 this를 사용해줘야한다. 
this.name 이런식으로

이렇게 필드변수값을 메소드내부에서 같은이름의 지역변수가 가리는 상황을 
변수 쉐도잉이라고한다
이경우는 생성자에서 매우 자주 발생한다

1-2 변수 하이딩


필드변수값


int level 10000000;

이 부모가 가진값이고


자식이 부모를 extends 했지만

자식역시 같은 int level 을 선언하였고 그 값이 다르다면

이 경우 

자식은                

ex) int level 2000000000;

2000000000 / 10000000  

이렇게 갖게되고

자식의 level값 호출시 ( 자식클래스타입의 참조변수로 부른 자식타입의 인스턴스시 )
2000000000이 나오게된다

하지만 여기서 부모타입의 참조변수로 해당 자식타입인스턴스 조종하여 해당값 출력시엔
10000000라는 숨어있던 부모의 필드변수값이 튀어나온다

이렇기에 하이딩( 숨어있다는 ) 말이다.
하지만 현업에서는
부모와 자식이 같은 필드변수명 다른필드변수값을 갖는것은 다른 협업자에게 배려가아니므로
어지간해서는 없는상황이다.
