변수 쉐도잉 <-- 지역변수 필드변수 or 이너클래스 상황간에

가장 가까운 변수가 먼 변수를 가리는 상황을 의미함


변수 하이딩

같은 필드변수명의 변수들을 부모 자식 전부 선언하고
둘의 값이 다를경우

자식은 부모의 필변값 자기의 필변값을 갖되 

자신의 필드변수값이 부모의 필드변수값을 가리는상황이고

그것은 오직 부모의 참조변수로 해당 필드변수값호출했을경우에만나온다



예외처리

예외처리는
내가 만든 코드의 안정성을 위해 존재함
내가 생각했을때 내 코드를 사용자가 사용함에 있어
발생할만한 예외 (EXCEPTION)의 경우를 미리
내가 코드를 짜서
해당 예외가 발생하더라도 
프로그램이 죽지않도록함

구성은 Try Catch Finally 구조가 가장 일반적이며

이 경우

Try에 

예외가 발생할만한 상황을 넣어준다

문장이 1 2 3 세문장이고

2번쨰줄에서 예외가 발생할만한 상황이라면

그 상황에서 즉시 catch 로 넘어간다
고로 3번쨰 문장은 씹히는거다

그렇게 예외 발생시 바로 catch 로 넘어가서

Catch 문에서 
예외 발생에 대한 
대응을 하게된다

이경우 

Catch( 예외/오류 코드  네임태그 아무거나 ) {

대응문 }

이렇게 구성된다
여기서 
네임태그.getMessage();
 메소드 사용시
어떠한 오류인지 더 자세히 미시적으로알수있다

//이 getMessage는 내장메소드인건가 자바에 자체적으로 존재하는??

내가 예외가 일어나건 안일어나건간에 항상 실행케하고싶은 
문장은 Finally에 넣어 마무리한다
