1. Network Interface 설정 및 Routing Protocol 설정
라우터가 통신을 하기 위해서는 인터페이스에 IP를 할당하고, 경로를 찾아줄 라우팅 프로토콜이 필요합니다.

Interface 설정:

configure terminal (설정 모드 진입)

interface [인터페이스명] (예: interface fastEthernet 0/0)

ip address [IP주소] [서브넷마스크]

no shutdown (포트 활성화 - 매우 중요)

Routing Protocol 설정 (예: RIP 사용 시):

router rip (RIP 모드 진입)

network [해당 라우터가 연결된 네트워크 주소] (라우터가 알고 있는 네트워크 대역 광고)





2. Network Topology에 따른 라우터 구축 및 확인
5개의 라우터가 연결된 토폴로지(Topology)에서는 각 라우터가 서로의 네트워크 정보를 교환할 수 있어야 합니다.

구축 순서:

각 라우터의 인터페이스 IP 설정: 모든 라우터의 연결된 인터페이스에 올바른 IP 대역을 할당합니다.

라우팅 테이블 구성: 모든 라우터에서 동일한 라우팅 프로토콜(RIP, OSPF 등)을 설정하거나, 정적 경로(Static Route)를 지정하여 전체 네트워크 대역을 통신 가능하게 합니다.
