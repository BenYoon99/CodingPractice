1. 동등계층 통신의 개념을 설명하시오

답변: 동등계층 통신(Peer-to-Peer Communication)은 네트워크의 동일한 계층끼리 논리적으로 직접 통신하는 것처럼 동작하는 개념입니다.
 실제로 데이터는 아래 물리 계층까지 내려갔다가 다시 올라가지만, 각 계층은 상대방의 동일한 계층이 붙여준 헤더 정보를 해석하며 통신합니다. 
예를 들어, 송신측의 4계층(전송 계층)은 수신측의 4계층과만 대화하는 것처럼 동작하며, 이를 위해 각 계층 간의 프로토콜 데이터 단위(PDU)가 규격화되어 있습니다.

2. Data encapsulation 과정과 de-encapsulation 과정을 설명하시오

답변: 데이터 캡슐화(Encapsulation)는 상위 계층에서 내려온 데이터에 각 계층의 특성 정보를 담은 '헤더'를 덧붙여 하위 계층으로 보내는 과정입니다.
 4계층의 세그먼트, 3계층의 패킷, 2계층의 프레임 순으로 포장되는 식입니다. 반대로 역캡슐화(De-encapsulation)는 수신 측에서 하위 계층부터 상위 계층으로 올라가며 
각 계층의 헤더를 하나씩 제거하고 원본 데이터를 복원해가는 과정을 말합니다.

3. OSI 7계층 중 응용계층의 기능을 응용계층에서 수행되는 프로토콜을 기반으로 하여 개념적으로 설명하시오

답변: 응용계층(Application Layer)은 사용자가 네트워크 서비스에 접근할 수 있도록 인터페이스를 제공하는 역할을 합니다. 단순히 '앱' 자체라기보다는 네트워크 서비스를 사용하는 통로라고 보면 됩니다. 대표적으로 웹 브라우징을 위한 HTTP, 파일 전송을 위한 FTP, 메일 송수신을 위한 SMTP, 도메인 이름을 IP로 바꿔주는 DNS 같은 프로토콜들이 이 계층에서 동작하며, 각 서비스 목적에 맞는 통신 규약을 정의합니다.

4. OSI 7계층 중 표현계층의 기능을 설명하시오

답변: 표현계층(Presentation Layer)은 송수신측이 서로 이해할 수 있는 공통된 데이터 형식을 정의합니다. 주요 기능으로는 데이터 인코딩(ASCII, UTF-8 등),
 보안을 위한 암호화 및 복호화, 전송 효율을 높이기 위한 데이터 압축 등이 있습니다. 즉, 하위 계층에서 올라온 비트열을 응용 계층이 이해할 수 있는 포맷으로 변환해주거나 그 반대의 역할을 수행합니다.

5. OSI 7계층 중 세션 계층의 기능을 설명하시오

답변: 세션 계층(Session Layer)은 응용 프로그램 간의 통신 세션을 설정, 유지, 종료하는 역할을 합니다. 통신 도중 연결이 끊기지 않도록 관리하는 '대화 제어(Dialogue Control)'가 핵심이며, 
데이터 전송 도중 에러가 났을 때 복구할 수 있도록 체크포인트를 설정하는 '동기화' 기능도 수행합니다. 쉽게 말해 통신의 시작과 끝을 관리하는 관리자 역할을 한다고 볼 수 있습니다.
