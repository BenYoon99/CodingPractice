컴퓨터 네트워크란 

하나의 디바이스와 다른 디바이스간 연결된 것을 의미한다.
하나의 디바이스와 다른 디바이스는 각각 하나의 노드인데
그 노드들은 관계로 엮여있는 ( 관계 == 링크) 상태이다.
그리고 그 edge ( 가장자리)에 위치한 것들이 
데이터 수신자와 데이터 송신자이다.
이 두개가 시작과 끝이다.
고로 컴퓨터네트워크란

노드간의 관계이고
시작은 데이터송신자 A노드 

끝은 데이터 수신자 B노드인것이다

데이터를 보내는 과정에서 
현재 세대에서 가장 빈번하게 택하는 택틱은
Encapsulation 캡슐화이다.
캡슐화는 
우리가 보내는 데이터를 편지라고 가정시 OSI 7계층에서 
일정 계층들에서 헤더를 붙여 패킷화 시키는것을 의미한다.

데이터를 보냄

헤더 데이터


헤더 헤더 데이터


헤더 헤더 헤더 데이터

이런식으로 마르툐시카처럼 데이터가 헤더 즉 상자에 덮혀있는 형태라고 생각하면 편하겠다.

여기서 그럼 왜 우리는 이런 헤더를 붙일까

그것은 데이터 송수신의 효율성을 위해서다.
데이터 송수신을 할떄 
다음 계층은 굳이 데이터의 내용을 알필요가 없는 경우가있다
왜 why?
예를 들어
우리가 편지를 보낸다면
편지를 보내주는 기사님은 편지의 내용이 중요한것이아닌 편지가 어디로 가야하는지가 중요한것이다
예를들어 네트워크계층 L3 에서는 라우팅을 통해 해당 장소까지의 경로를 최적화 해야하는데
그 최적화과정에서 데이터의 내용이 중요한것이아닌 그 데이터가 도착해야하는 장소가 중요한것이다 
고로 그 윗단계에서는 해당 주소에대한 경로 최적화가 중요하기에 주소에 해당하는 헤더를 붙여 데이터를 L3에 전송한다.

그럼 여기서 
Osi 7계층을 어떤식으로 이해하고 암기해야할까

우리가 데이터를 송신자라 가정하고 보낸다면
우리는 L7 부터 아래로 L1 단계로 헤더를 붙여나가 캡슐화 전송을 하고 
L1에서 전기신호로 변환후 수신자에게 전달된다 
수신자는 전달받은뒤 L1 부터 L7단계까지 위로 하나씩 가장 밖( which means 가장 최신의 헤더를 ) 뜯어내면서 최종적으로 데이터를 수신한다.


이 방식은 데이터를 잘게 조개서 ( 패킷화 시켜서 ) 보내는것이다,
그 뒤 수신자는 그 패킷화된 데이터를 다시 합쳐서 보는것이다.
이게 가장 상용화된 현재의 네트워크 송수신 방식이다.
