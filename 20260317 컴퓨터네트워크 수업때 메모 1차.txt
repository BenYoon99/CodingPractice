왜 우리가 컴퓨터 네트워크를 배우는가

컴퓨터 네트워크를 배워 OSI 7계층구조를 이해해야
모두가 사용하는 
7계층중 내가 어떠한 부분을 사용하는지 그리고 코드 구조에 있어서 
추후 어떠한 부분을 보완해야 계층부분중 어디의 어떠한 기능이 보완대는지 알기 용이하기에


그럼 왜  컴퓨터 네트워크 - OSI 7계층이 필요할까

OSI 7 계층은 매우 중요하다고 한다 그럼 왜 중요하냐?
이건 우리가 서버 ----- 서버 간 통신함에 있어서 
국제적으로 다같이 사용하는 규격인것이다.
이게 없다면
내가 어떠한 정보를 카카오톡으로 전달하고싶어도 
해당 내용 전달에 필요한 기술을 전부 마스터하고 그걸 이용하지않고서는 불가능해진다.
하지만 OSI 7계층구조 덕분에 
우리 개발자들은 7계층 ( 인터페이스 및 사용자 화면) 만 신경쓰면 되고 
나머지 기능구현은 나머지 계층에서 자동적으로 해준다.

고로 이  정형화된 구조로 우리는 일을 함에 용이하고 , 더군다나 트러블 슈팅시에 어떤 부분에서 문제가 생겼는지 명확히 파악하기 쉽다,
왜냐하면 각 계층마다 정해진 역할이 있기에 해당 역할에 영향이 있다면 , 체크하기가 용이하기 떄문이다.

7계층의 구조와 역할 (Encapsulation) 


7  6 5 ( 내용물을 직접 작성후 봉인하는 단계)

데이터를 선정후 상자에 담고 봉인한다.

4계층 전송계층 

여기선 TCP 헤더 주소가 이전의 데이터와 붙는다

고로 데이터 + TCP 헤더주소 == [세그멘트] 

그 두개를 세그멘트라는 상자로 덮는다고 생각하면 편하다 , 실상은 데이터와 TCP 헤더주소가 합쳐져 세그멘트가 되는것이다.

3계층 네트워크 계층

L3 헤더주소가 여기서는 붙는다 이전 정보와함께 
고로 

L3 헤더 + 세그멘트 == [패킷]

2계층 데이터 링크 계층

L2 헤더주소가 여기서 붙는다.

고로 

L2 헤더 + 패킷 == [프레임]

1계층 물리계층 

이 구간은 간단히 상하차 배달 계층이라고 생각하면 편함
7~5에서 고르고 밀봉입한 데이터를 담은 상자를 담은 세그멘트를 담은 패킷을 담은 프레임을 0 , 1 등의 전기신호로 변환후 광케이블이용해서 실제 물리적 상대에게 쏴준다.

비유하자면 실제로 너가 전부 포장을 끝낸 상자가 택배차를 타고 고속도로를 타고 상대에게 가고있다고 생각하면 된다.

이 프레임을 받은 사람은
 그 프레임 내부의 실질적 데이터값을
알려면
역으로 위 과정을 반대로 해야한다.
그걸 역 캡슐화라고한다.

프레임 - 패킷 - 세그멘트 --- 데이터 (실질적값)


그럼 이러한 과정을은 도대체 왜 하는 것일까?

이 과정을 하는 이유는 아직 자세히 배운것은 아니지만

택배 기사가 택배를 하는 과정에서 그 해당 내용물을 알필요없이 주소만을 알면되기에 
해당 주소명을 캡슐화과정속에서 기입하며 넘어가 불필요한정보를 컴퓨터가 먹지않고 최대한 최적화로 굴리기 위해서다.


HTTP DAEMON은
실제로 백그라운드에서 응답을 기다리며 24시간 대기하는 놈이다 .

형이 이전 웹서버 아키텍쳐 최초  CLIENT 위에 DEMON이 있고 거기서 최초 스타트가 된다고 했엇는데 그게 이 데몬과 무슨 연관인지 궁금하다 


그리고 내가 자바에서 배우는 캡슐화와 이 네트워크 캡슐화의 연관성도 궁금하다

자바에서는 클래스 내부변숫값을 private으로 숨기고 public 메소드로 밖과 소통 (getter setter)하여 데이터를 감싸는데
이것과 무슨 관련이 있는지 궁금하다. 

자바에서의 캡슐화와 네트워크에서의 캡슐화 모두 

추상화를 목표로 하고 하는것이다.

추상화란

너가 알아야할 정보만을 제공 , 몰라도 되는건 나만 알래이다.

이 점에서 자바의 캡슐화는 정보의 보안성의 측면이고.

네트워크의 캡슐화는 계층화로 일의 정형화의 측면인것이다.

자바 : 내부 변수의 변동은 니가 알빠아니야 , getter setter로 소통하자

네트워크 :           OS , Hardware : 데이터가 어떤 내용을 갖고있던 무슨상관이야 우리는 IP주소보고 배달이나하자 ( IP주소를 나타내는 헤더주소가 그 역할 불필요한 정보를 컴퓨터에 줄필요없이 그냥 알아야하는 정보만으로 최적화 )
