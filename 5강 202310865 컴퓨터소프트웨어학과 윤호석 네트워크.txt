1. TCP vs UDP


연결방식의 차이

TCP 는 연결지향 -- 안정적임

UDP 는 비연결지향 -- 상대적 비 안정적


신뢰성의 차이

TCP는 높다

UDP는 낮다 ( 데이터가 유실될 가능성 있음)

속도의 차이

TCP는 상대적으로 느림 ---> Overhead occurs

UDP 매우빠름

통신방식의 차이

	TCP == 1:1 통신

	UDP == 1:1, 1:N, N:N 통신을함

주로 사용하는 용도의 차이

	TCP == 웹 이메일 파일전송

	UDP == 실시간 스트리밍 , 게임 ,DNS에 사용됨


2. 네트워크 계층의 IP 

IP는 네트워크 계층의 핵심 프로토콜로 
데이터 패킷을 송신------ 수신 까지 전달하는 역할입니다.


해당 IP의 주요역할로는

논리적 주소를 지정하고 
경로를 제어하며
데이터를 ---> 패킷형태로 단편화시킵니다.
하지만 IP는 비연결성과 비신뢰성을 가집니다 ( 데이터수신측의 상대방을 확인하지않고 데이터가 순서대로 도착되거나 유실되지않는걸 보장하지않습니다)


3. Ping Procedure

1. src --> user  type ping

2. OS/app Layer ICMP 패킷 생성

3. 네트워크계층이 ARP --- 맥주소 취득

4. 로컬게이트웨이 --> 우리 동네인 우리 로컬네트워크 벗어나기위해서 기본게이트웨이 ( 아파트로치면 단지 입구) 로 전송

5. 라우팅 결정  --> 중간 라우터들이 목적지 IP 분석 routing table 조회후 next hop 결정 및 Optimization (경로 최적화)

6. 전송 --> 홉 by 홉

여기서 홉은 지나친 라우터의 수임
