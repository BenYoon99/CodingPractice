소규모 네트워크를 의미한다

WAN 광역  통신망 (Wide  Area Network)

대규모 네트워크를 의미한다.

WAN 설계 목적 

WWW ,전자메일 , 파일전송, 전자 상거래 서비스 
( 전부 지역에 국한된 네트워크로 불가능 광범위적 네트워크가 요구되기에 )


WAN 커버 가능 범위  == 수십 km ~ 수백 km






MAN 도시권 통신망 (Metropolitan Area Network)


MAN은 WAN 보다는 작지만 LAN 보다는 큰 지역에 산재하는 사용자들을 상호연결하는데 사용되는 통신망을 의미한다.


영역의 크기차이 

WAN>>> MAN>>>LAN 

MAN은 도시권역에 있는 네트워크를 하나의 더 커다란 네트워크로 연결하고 
이는 다시 WAN 에 효울적으로 연결된다 


MAN 커버 가능 범위 == 2~40km 정도  so we use it in 도시환경

MAN 예시

도시내 MAN

Building A <---------------> 2~40km far away  Building B

SAN  (Storage Area Network)

서버와 저장 장치간에 데이터를 전달하는 고성능 전용 네트워크를 의미함.

SAN 의 특성

SAN은 독립된 전용 네트워크이기에 
클라이언트 -----서버 간 어떠한 트래픽 혼선도 존재하지않는다.

기존의 네트워크와의 연결성 문제를 해결하기위해 독립된 네트워크 인프라를 사용한다.




데이터 센터 ( Data Center)

인터넷 인프라상에서 서로 상호간 정보 전달의 용이성을 위해 효율적으로 구성 /설계해놓은 네트워크를 의미한다.


인트라넷 (Intranet)

LAN의 구성 방법중에 하나이다 

기관 내부 LAN에 접속 권한을 갖고 있는 사용자만이 접속할수있도록 설계되어있다.

LAN 로컬 애어리어 네트워크
한마디로 로컬한  네트워크중

접속 권한이 있는 사람만 접속할수 있게끔 설계한놈이다.

고로 쉽게 생각하면 LAN 중 더 보안이 좋은놈임 .




익스트라넷(Extranet)

인트라넷 중에 CERTIFIED 된 외부 사용자로 한에 부분적으로 이용할수있게끔 설계된 인트라넷



가상 사설망 (Virtual Private Network)

인터넷과 같은 공중 네트워크 인프라 상에 구현된 사설의 망을 일컫는다.


디지털 대역폭 (Digital Bandwidth)

정해진 시간 동안 네트워크 연결을 통해 전송될수있는 정보의 양을 말한다.

디지털 대역폭 측정 (Digital Bandwidth Calculation)

디지털 시스템에서 대역폭의 기본단위는 초당 비트수이다.
( bps bits per second)

대역폭 단위 

대역폭 단위               약어              등가값
bits per second  bps   bps              1bps ( 대역폭의 기본단위)

kilobits per second    Kbps              1Kbps = 1000 bps 

Megabits per second  Mbps             1Mbps =1000000 bps 

Gigabits per second   Gbps              1Gbps = 1000000000 bps

제 5계층 세션 계층 session layer


제 4계층 전송 계층 transport layer

제 3계층 네트워크 계층 network layer

대전에서 라우터이용 천안으로 쏴주고 천안라우터 이용해서 서울 특정구로 메세지를 쏴주면 되는것이다.
