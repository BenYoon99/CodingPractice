1. 변수 그리고 리터럴 


변수란 우리가 자바를 사용할때 일정한 값을 넣어주는 상자이다

예를 들자면 정수 4라는 수를 어떠한 문자에 넣어두고 해당 문자를 불를때 해당 4라는 수가 나오게 하고싶다면

우리는 이러한 접근을 할것이다.


int four = 4;

이 상황에서

four은 변수 variable 이고

4는 literal 리터럴이다.




2.  자동형변환 Casting


자바에서는 연산이나 대입을 하게 되는 경우
서로간의 데이터 타입이 같아야한다

여기서 데이터란 말그대로 정보 쪼가리 그자체이고

데이터 타입이란 한국명 자료형 즉 그 정보쪼가리의 형태들을 나타내주는 변수명들을 말한다.

정수형의 대표적 데이터타입은 int

실수형은 double

문자열은 String

문자는 char

이렇게 되어있다.

여기서 문자열은 시작값이 대문자인데
이것은 우리가 String이라는 외부클래스를 불러 사용하는것이기에 클래스명네이밍법칙인 첫글자 대문자를 따서 저렇게하고 나머지는 변수 카멜케이스 네이밍법칙에따라 소문자로 시작한다.


이어서 자동형변환을 설명하겠다. 

서로 다른 데이터타입간에 연산이나 대입을 진행하고싶을때 우리는 형변환 Casting을 사용한다
하지만 여기서 중요한 법칙이있다.
데이터 타입의 크기에 따라서 자동형변환의 적용유무가 갈린다.
자동형변환이란  ( 코드로 설명하겠다)


int rabbit  = 4;
double frog = 8.89;
frog = rabbit;


위 코드를 보자 

우리는 4바이트의 데이터타입형태의 변수 rabbit과 8바이트의 데이터타입 변수인 frog를 생성하였다.
그리고 frog라는 실수형 변수에다 우리는 정수형 변수의 값을 대입했다.
이 경우 내가 위에서 말했다싶이 자바는 같은 형끼리만 대입연산이 가능하다했는데 그럼 이건 오류를 뿜어낸다고 판단하는것이 맞다,
하지만 자바는 자동형변환이라는 기능이있다.
더 작은 바이트의 데이터타입 --------> 큰 바이트의 데이터타입에 대입 연산을 진행하는경우에는

자동으로 작은 바이트의 데이터타입을 큰 바이트의 데이터타입으로 형변환 시켜준다
이것을 자동형변환이라고 부른다.

고로 위 코드는 정상적으로 코드가 작동되고

해당 코드에 후첨으로 System.out.println(frog);
를 진행하게 된다면 

4.0 ( 4라는 정수를 실수형으로 자동변환해준 모습)
이 출력되게 된다.

그럼 

역의 상황에서는 어떻게 진행이 될까

rabbit = frog;라는 상황이라면

이 상황에서는 자바는 에러를 뿜어낸다 
왜냐하면
정수형의 상자에 실수형의 값을 넣게되면
우리는 실수형의 소숫점뒤 숫자들이 전부 날라가기에 원 데이터와 다른 데이터가 전송되는것이기에.
고로 이 경우에는 우리가 만약 그걸 고려하고도 해당 변수에 실수값을 넣어주고싶다면 
강제형변환 / 명시적 형변환
을 사용해주어야한다.
명시적 형변환이란 서로다른 데이터타입중 넣으려는 상자보다 작은 크기의 데이터타입의 변수앞에  ( 위 double 8bytes - int 4bytes)
넣는 상자의 데이터타입을 선언해주어 명시적으로 형( datatype)을 변경해주는것이다.



-->

rabbit = (int) frog;

System.out.print(rabbit);

이렇게 된다면 

출력값은 8이된다
( .89가 정수형이되며 잘린모습) 



-- 더 쉽게 나의 언어로 정리하자면 형변환은 "코끼리를 냉장고에 넣기" 이다.

작은 토끼는 냉장고에 들어간다면 그냥 아무일도 일어나지않고 그냥 잘 들어가겠지만

코끼리를 냉장고에 넣게 될 경우에는 냉장고에 들어가지 않고 남은 살점을 어떻게하시나요 ( 소숫점등 / byte 크기) 
그걸 감안하고 넣으시겠어요? --> YES ---> 명시적 형변환 / 수동적 형변환 인것이다.



3. 문자열 

우리는 자바에서 문자열을 표현하고 싶을때 

String이라는 클래스를 불러와 사용한다  ( 참조 클래스) 

고로 이 경우 다른 데이터타입들과 다르게 시작점이 S 대문자인것을 알수있고
또한 해당 외부클래스의 메소드들을 제공받아 사용이 가능하다.
String의 값을 넣을땐 "" 안에 넣어주어야하며 
'' 이렇게 홑따옴표의 경우에는 문자 char을 나타냄으로 주의해야한다.

이제 String이 제공하는 대표적인 메소드들을 이해해보자

1. length();

이것은 문자열의 길이를 return 해주는 메소드이다
코드 예시를 들어주겠다.


String ex1 = "gimbap";

int ex2 =  ex1.length();

System.out.println(ex1.length());

double ex3 = ex1.length() 

이경우 ex1이라는 문자열 데이터타입의 변수에 gimbap이라는 6글자의 리터럴을 넣은 모습이다.

그리고 length라는 문자열외부클래스가 제공하는 메소드를 사용해 해당 글자의 길이를 리턴받은모습이고
해당 문자열의 길이는 결국 몇 '개' 이기에 결국 정수형태를 띄게 될것이다.
고로 integer 형태로 나타난다는소리고 그말인즉슨 결국 이것은 int형에 넣을수도 있는것이다.
그리고 응용한 자동형변환 규칙까지 생각하면 
6.0으로 자동변환되어 ex3에 대입까지 성공적으로 되는 모습이다.


2. equals();

이것은 문자열 1과 문자열 2가 같은지를 판명해주는 메소드이다.

코드로 설명하겠다.

String ex1 = "gimbap";
String ex2 = "gimbap";
String ex3 = "kimbap";

boolean isSame = ex1.equals(ex2);
boolean isntSame = ex1.equals(ex3);

System.out.print(isSame);
System.out.print(isntSame);


이 경우 ex1 과 ex2 은 같고 ex1 ,2와 3은 다르기에 
ex 1과 ex 2비교 - equals() 메소드 사용시 참이 나오게된다 ( 불리안 메소드이기에 )
고로 불리안 데이터타입 변수에 저장이 가능하다.

저경우에 
출력값은 true , false 가 된다.


2-1 불리안 데이터타입의 특별한 특징 

불리안 데이터타입을 저렇게 넣었는데 우리가 오늘 배운 강제형변환과 명시적 형변환을 이용하면 우리는 불리안과 다른 데이터타입간 교류가 가능해보인다
하지만 그것은 틀렸다.
불리안 데이터타입은 명시적 /수동  형변환 , 자동형변환 둘다 받지않는 특수한 데이터타입이다. 
고로 이 데이터타입을 다룰땐 다른 데이터타입과 교류가 아예 되지않는 
true false 리터럴만을 받고 다루는 데이터타입이라는 점을 기억해야겠다.
