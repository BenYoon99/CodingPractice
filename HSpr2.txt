0 배열 

 배열은 쉽게 생각하자면 호텔짓기이다( 내방식대로의 생각)

구성은 이렇게된다 

int [] arr;   // 배열선언 
arr  = new int [5]; // 배열의 방파기 
arr [0] = 123123; // 배열 안에 정보집어넣기 
System.out.println(arr[0]); // 배열방 0번방안의 정보값확인 

근데 이렇게 생각하면 편하다 
int [] arr;   // 자료형 호텔 호텔명 ( 나는 정수형 손님만 받는 호텔만들거고 그 호텔이름은 arr이여) 
arr  = new int [5]; // 호텔 방갯수 만들기 (arr이라는 신축호텔에 방 5개를 만들거고 거기는 정수형손님만 들어올수있어 ) 
arr [0] = 123123; // arr 호텔의 0번방에는 123123손님이 들어감  
System.out.println(arr[0]); // 호텔방안의 0번방에 어떤손님들어갓어? 체크하자
