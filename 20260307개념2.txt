예외처리 방식 !


try {
 1. 위험구역 : 사고가 날것같은 코드를 여기에 넣는다.}
catch (사고종류 e){
2. 대처구역: 만약 사고가 나면 일로 점프한다 여기서 수습한다.}
finally {
3. 뒷정리 구역 : 사고가 나든 안 나든 " 무조건 " 마지막에 들리는 곳이다
}



public static void main(String args[]){
 
String str = null;
	
try{ 
int length = str.length();
System.out.println("널값이 발생했습니다 ");
}
catch(NullPointerException e){
System.out.println("문제 분석들어갑니다...");
System.out.println("문제는 : "+e.getMessage());
}
finally{
System.out.println("문자갯수 구하느라 고생하셨습니다.");
}

.length();
