/*🔱 퀘스트: 상어의 바다 생태계 관리 시스템 ( 제미나이 자체제작 문제 ( 3회 출력오류 후 출력성공)
[문제 시나리오] 상어님은 지금 '태평양'이라는 이름의 바다 생태계를 관리하는 백엔드 개발자입니다. 바다에는 여러 종류의 생물이 살고 있으며, 
각 생물은 저마다의 방식으로 '이동'합니다.

[요구 사항]

부모 클래스: SeaCreature

메소드: public void move() -> "물속을 헤엄칩니다."라고 출력.

자식 클래스 1: Shark

SeaCreature를 상속받음.

move() 메소드 오버라이딩: "상어가 강력한 지느러미로 빠르게 헤엄칩니다!" 출력.

자식 클래스 2: Guppy

SeaCreature를 상속받음.

move() 메소드 오버라이딩: "구피가 어항 속에서 살랑살랑 헤엄칩니다." 출력.

메인 클래스: OceanMain

크기가 3인 SeaCreature 타입의 배열을 생성하세요.

if-else문을 사용하여 배열의 각 인덱스에 객체를 할당하세요.

0번 인덱스: Shark 객체

1번 인덱스: Guppy 객체

2번 인덱스: Shark 객체

for문을 돌리면서 부모 타입의 참조 변수를 이용해 각 객체의 move() 메소드를 호출하세요. (동적 바인딩 확인)*/


import java.util.*;
import java.lang.*;
import java.io.*;

// The main method must be in a class named "Main".
public class Main {
    public static void main(String[] args) {
        SeaCreature s1 = new Shark();
        SeaCreature g1 = new Guppy();
        SeaCreature s2 = new Shark();
        
        SeaCreature [] Seacreatures = new SeaCreature[3];
        int i=0;
        if(i==0){
                Seacreatures[i]=s1;}

         i=1;
         if(i==1){
                Seacreatures[i]=g1;}
        i=2;
        if(i==2){
                Seacreatures[i]=s2;
        }

        
        
        for(i=0;i<3;i++){
                Seacreatures[i].move();    
        }

        
    }
        
        }
        
        
    

class SeaCreature{
        public void move(){
                System.out.println("수영친다");
        }
}

class Shark extends SeaCreature {
        @Override
        public void move(){
                System.out.println("상어가 강력한 지느러미로 빠르게 헤엄칩니다!");
        }
}

class Guppy extends SeaCreature {
            @Override
            public void move(){
                    System.out.println("구피가 어항 속에서 살랑살랑 헤엄칩니다.");
            }
}
