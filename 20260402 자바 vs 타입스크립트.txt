Java 

참조는 공통점 같는다

자바는 객체생성을할떄 예를들어보자

Babo babo = new Babo("babo1", 15);

로 객체를 생성하면

우리는 

스택영역에 해당클래스타입의 참조변수를 생성후 해당 참조변수에 힙영역에 new로 자리를 파고 생성자입력정보를 들고 태어난 인스턴스의 주소를 쏴준다( 인스턴스는 힙영역에 만들어져있기에  스택<-------힙 이다 )
