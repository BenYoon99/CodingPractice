//컴퓨터 네트워크 개념 예습

컴퓨터 네트워크는 네트워크에 대해서 배우는것이다

그 네트워크는 매우 복잡합니다 

그렇기에 공학자들은 네트워크를 총 7개의 층(Layer)로 나눴습니다.

각 층이 자기 할일만하면 전체 통신이 돌아가게끔 설계한것입니다.
우리는 이 구성을 추상화 abstraction 이라고합니다


7계층 구조 

1. 하위 계층 ( 물리적인 전달을 담당함 - 배달원을 생각하자 )
//여기서의 아래의 L들은 Layer이다
L1 
물리계층 ( physical) 
실제 케이블과 전선등이다.
집-------------------------------------------집2  //요 선이 L1 물리계층

이렇게 연결되어있어서 
	보내는 데이터를 0과 1(비트)라는 전기신호로 바꾸어서 옆집으로 보낸다.


L2 데이터 링크 계층 ( data link )

물리적으로 연결된 두 장치간의 통신을 담당한다. 

집(장치 ..  ) ---------------------------------------------집2 ( 장치 ..)
이렇게되면 이렇게 물리적으로 각 집간에 통신이 연결된건데
이 통신이 연결된 거에서 이 통신을 담당하는게 data link 계층이다
여기서 중요한건 MAC주소(랜카드 고유번호이다)
 - MAC주소가 뭐냐?
	MAC주소란 
 		IP 주소와 다르게 IP 주소는 해당 위치의 모든 기기가 공통적으로
			갖는 값이지만 
		MAC 주소는 기기 생성시 각 기기당 하나의 값만을 갖는거임
		고로 예를들면 
		강서구 화곡동 우리집에서 나와 형 이 따로 컴퓨터를 갖고있으면
		둘의 ip 주소는 아예일치하지만
		나와 형의 컴퓨터 MAC주소는 다른거임
		왜 why 형의 컴퓨터와 내 컴퓨터는 만들떄 MAC주소를 다르게
		지었기에
		그걸로 구분이 가능하다.

L3 네트워크 계층 :IP주소 
 
IP주소는 위에 말했다싶이 
각 기기의 주민등록번호와 같은 MAC주소와 다른 
지역의 주소이다

고로 예를들자면
내가 LG GRAM을 샀고 그 MAC주소가 1이고 대전에서 사용중일때의
IP가 2라고 한다면

그 MAC주소는 태어남과 동시에 영원히 1이지만
내가 편입을 성공해 대구로 이사를 가게된다면 대구의 IP주소가 3이라면
내 LG GRAM은 MAC주소 1 IP 주소 3이되는거다
그렇게 각 지역의 IP주소를 할당받는것이다
이렇게 IP 주소를 할당받을떄 내가 생각해야하는건 
 라우터/라우팅이라는 개념이다

라우터이란 L3에서 가장 중요한 Device 장치이다
라우터는 내가 IP값을 받기 쉽게하기위해 
데이터패킷을 그 IP값에 잘 안내하는 장치이고
그 과정을 라우팅이라고 한다. 
 EX) 대전 라우터 (출발지 )    ==============              대구 라우터 (목적지)
