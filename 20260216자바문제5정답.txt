2. 부모 클래스 설계
이름: Product

필드(변수): String name, int price

생성자: 이름을 받아서 필드에 저장하는 생성자 만들기

3. 자식 클래스 설계

상속 및 구현: Product를 상속받고, Item을 구현하세요.

오버라이딩: showInfo()를 구현하여 "제품명: [name], 가격: [price]원"이 출력되게 하세요.

4. 메인 로직 (Main 클래스)
ArrayList<Electronics> 가방을 만드세요.

Scanner로 제품 3개의 이름과 가격을 입력받으세요. (반복문 사용!)

입력받은 값으로 Electronics 객체를 만들어 리스트에 add() 하세요.

마지막에 향상된 for문을 써서 리스트에 담긴 모든 제품의 showInfo()를 실행하세요.*/

import java.util.ArrayList;
import java.util.Scanner;
interface Item{
    void showInfo();
}
class Product{
    String name;
    int price;

    Product(String name, int price){
        this.name = name;
        this.price = price;
        
    }
}
class Electronics extends Product implements Item {
    Electronics(String name , int price){
        super(name,price);
    }
    @Override

    public void showInfo(){
        System.out.println("제품명:"+name+"가격:"+price+"원");
        
    }
}
class Main {
    public static void main(String[] args) {
        ArrayList<Electronics> elec = new ArrayList<>();
        Scanner sc = new Scanner(System.in);
        System.out.println("전자제품 정보를 받습니다 ");

        for(int i=0;i<3;i++){
            System.out.println("전자제품의 제품명을 기입해주시요:");
            String n = sc.next();

            System.out.println("전자제품의 가격을 기입해주세요:");
            int p = sc.nextInt();

            elec.add(new Electronics(n,p));
            
        }
        for(Electronics e: elec){
            e.showInfo();
        }
        
    }
}
