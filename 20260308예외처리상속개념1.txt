여기서 왜 new 가 쓰이냐 할수있고

여기서 throw로 굳이 수동 예외 유발을 하지않아도

4-1 예외클래스 상속관계간 super기능


class InvalidToeicException extends RuntimeException {
        InvalidToeicException(String errorName){
            super(errorName);
        }
}   
class Main {
    public static void main(String[] args) {
        int score = 1000;
        try{
            if(score>990){
                throw new InvalidToeicException("990점이상의 점수는 존재가 불가능합니다");
            }
            
        }
        catch(InvalidToeicException e){

            System.out.println("에러가 발생하였습니다 에러내용은: "+e.getMessage());
            System.out.println("토익점수는 990점을 넘을수없습니다 입력칸으로 다시 이동후 입력해주세요");
            
        }
        finally{
            System.out.println("토익응시와 점수입력까지 고생많으셨습니다");
            
        }
    }
}

여기서  super(errorName); 
이 되어있는데
이상하게 생각할만하다
분명 가시적으로 보이는 부모클래스 RuntimeException이 없는데
뭐지 그럼 이럴것이다
하지만 부모클래스 RuntimeException은 예외 클래스로서 
Java.lang 에 기본패키지로 존재하며
그 내부에  public RuntimeException () 으로 생성자마저 파져있다
그 내부에는 detailMessage가 존재하기에
해당 분점의 생성자의 매개변수명이 무엇이든지간에


그 매개변수명이 가리키는 매개변수값을 

 

super을 사용해

본점에 방문 // RuntimeException 클래스

해당 생성자에 도착

생성자 규칙대로 해당 detailMessage라는 매개변수로 받아 
super내부의 detailMessage 필드변수값에 저장한다.
그렇게되면 
RuntimeException 타입의 참조변수로 해당 인스턴스 조종 , 해당 변수값 소환시 해당 값 나온다.

// 1. 본사의 매뉴얼 (부모 클래스)
class Student {
    String schoolName; // 본사 창고

    Student(String schoolName) { // 본사 매뉴얼: "받은 건 내 창고(this)에 넣어라"
        this.schoolName = schoolName; 
    }
}

// 2. 지점의 행동 (자식 클래스)
class KnuaStudent extends Student {
    KnuaStudent(String name) {
        super(name); // 👈 상어님이 말씀하신 "본사 매뉴얼을 따라라!"
        // 이 한 줄이 실행되는 순간, 본사의 'this.schoolName = schoolName;'이 실행됩니다.
    }
}
 

knuaStudent 클래스내부 생성자에서 
super 사용하자마자
name 필변값은

본점의 규칙이뭔데?
