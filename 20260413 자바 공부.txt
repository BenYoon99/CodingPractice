this() 생성자 

생성자 체인을 위해 사용됨

생성자 체인이란 동일 클래스 내부의 다른 생성자에서 하나의 생성자를 호출하는 프로세스로 
생성자는 다른 생성자에서만 호출 할수있으므로 생성자 체인이 필요하다.



생성자 체인이란 
한 클래스 내부에서 하나의 생성자에서 다른 생성자를 호출하여 연결고리를 만드는것을 말한다.


class Hero {
    String name;
    int level;

    // 이름만 받는 생성자
    Hero(String name) {
        this.name = name;
        this.level = 1; // 중복 발생!
    }

    // 이름과 레벨을 모두 받는 생성자
    Hero(String name, int level) {
        this.name = name;
        this.level = level;
    }
}
간단한 방식 



this() 사용시 

class Hero {
    String name;
    int level;

    Hero(String name) {
        this(name, 1); // "아래에 있는 매개변수 2개짜리 생성자한테 일 시키기"
    }

    Hero(String name, int level) {
        this.name = name;
        this.level = level; // 모든 초기화 로직이 여기서 관리됨
    }
}
