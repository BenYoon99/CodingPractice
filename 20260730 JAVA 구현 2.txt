상속이란  inherit 

해당 클래스 내부의 변수와 메소드들을 해당 클래스를 상속받은 다른 클래스들이 해당 메소드와 변수등을 갖게해주는것이다. 이로써 
하나의 클래스 ( 껍데기만 만들어도 ) 
로 다른 수많은 클래스의 기본 구조를 만들수있다.

예시를 들어보자면 

black white east asian south east asian 은 서로 다른 인종이기에 다른 특성 ( 피부색이 다르고 근섬유질등 DNA 구조의 차이) 를 지니지만 
rough 하게 생각하면 공통적으로 모두 인간이다 
그 말인즉슨 우리는 그들 모두가 갖는 특성들 == HumanTraits 라는 클래스를 파주고 해당 클래스에 
그들이 공동적으로 공유하는 메소드와 변수들을 넣어주게 된다면 우리는 굳이 
class Black class White 등등의 클래스에 일일이 메소드와 변수를 넣어줄 필요가없는것이다.

예시를 보자면

class HumanTraits {

int eyesight;
int age;
void eat(){
System.out.println(" 먹음");

}

class White extends HumanTraits { 
}


class Black extends HumanTraits{
}


White와 Black 클래스 내부에는 이미 
int eyesight와 age 등의 필드변수들과 그리고
eat 메소드가 이미 박혀있다
여기서 너가 해당 메소드의 Method Body 인 
먹음을 다른 메소드 본문으로 수정하고싶다면
그 경우 
@Override 어노테이션을 작성후
해당 내용을 수정하면 된다.

첫번째

하나의 추상메소드라도 존재한다면 그 클래스는 abstract 즉 추상클래스가 된다.
