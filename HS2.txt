// 배열정리 



배열은 걍 호텔만들기임 
단계별로 설명해주겟음

1.배열(호텔) 선언

 자료형 호텔명(배열의이름)  
int [] arr;      //나는  arr 이라는 호텔을 지을거고 여기는 정수형손님만올수잇음  c나 다른곳에서는 int arr[]; 도 되지만 자바에서는 그냥 자료형 배열 배열명 구조 ㄱㄱ 

2. 배열(호텔) 방파기
arr = new int[5];       // arr이라는 신식 호텔의 방은 5개여 근데 손님은 int 정수형만받는 방이야 
3. 정보값넣기(손님집어넣기)
arr[0] = 10;  // 여기서도 알겟지만 자바에서 방번호의 시작은 0번부터 10.1등 실수가 들어가면 에러뜸 정수형방이기에  
arr[1] = 10;
arr[2] = 10;
arr[3] = 10;
arr[4] = 10;
4. 값 조회해보기
System.out.println(arr[4]);


실무에서는 위 3단계를 생략해서 한번에한다함 


1번 방법 // 방개수만 정하기 
int [] arr = new int [5];

2번 방법 //데이터 넣고시작하기 (손님집어넣으면아 자바가 알잘딱으로 방파줌 ) 
int [] arr2 = {10, 20, 30}; // 어 손님이 3그룹이네 그럼 3개방만파면되겟네  ㅇㅋㅇㅋ 자바가 알잘딱
