1. 전송 계층(Transport Layer, 4계층)의 기능
전송 계층은 하위 계층(1~3계층)이 데이터를 물리적으로 전달하는 것에 집중하는 것과 달리, '양 끝단(End-to-End)의 사용자 간'에 신뢰성 있는 데이터 전송을 보장하는 역할을 합니다.

분할 및 재조합 (Segmentation & Reassembly): 상위 계층에서 내려온 데이터를 네트워크 망에 적합한 크기(세그먼트)로 나누고, 수신 측에서는 순서 번호를 확인해 원래 데이터로 합칩니다.

연결 제어 (Connection Control): 연결 지향형(TCP)과 비연결 지향형(UDP) 방식을 결정합니다. TCP는 3-Way Handshaking을 통해 통신 경로를 확립합니다.

흐름 제어 (Flow Control): 송신 측과 수신 측의 데이터 처리 속도 차이를 해결합니다. 수신 측의 버퍼가 넘치지 않도록 데이터 양을 조절하는 '슬라이딩 윈도우(Sliding Window)' 방식이 대표적입니다.

오류 제어 (Error Control): 전송 중 데이터가 유실되거나 손상되었을 때 이를 감지하고 재전송(ARQ)을 요청하여 무결성을 보장합니다.

포트 번호(Port Number) 할당: 프로세스를 구분하기 위해 논리적 주소인 포트 번호를 부여하여 데이터가 정확한 응용 프로그램에 도달하게 합니다




2. 네트워크 계층(Network Layer, 3계층)의 기능
네트워크 계층의 핵심은 **'경로 설정(Routing)'과 '논리적 주소 지정(Addressing)'**입니다. 데이터가 목적지까지 가장 효율적으로 갈 수 있는 길을 찾는 역할을 수행합니다.

라우팅 (Routing): 라우팅 알고리즘을 통해 송신측에서 수신측까지 가는 수많은 경로 중 최적의 경로(Best Path)를 선택합니다. 이 과정에서 라우팅 테이블이 사용됩니다.

논리적 주소 지정 (IP Addressing): 데이터 패킷 헤더에 송신자와 수신자의 논리적 주소인 IP 주소를 삽입합니다. 이는 전 세계 네트워크에서 단말기를 유일하게 식별할 수 있게 해줍니다.

패킷 전달 (Packet Forwarding): 라우터가 수신한 패킷을 적절한 출력 인터페이스로 넘겨주는 물리적인 전달 과정을 관리합니다.

혼잡 제어 (Congestion Control): 특정 네트워크 노드에 패킷이 너무 많이 몰려 전송 지연이 발생하는 것을 방지하고 흐름을 관리합니다.


3. TCP/IP 프로토콜의 개념과 구조
TCP/IP는 현재 인터넷 통신의 표준으로 자리 잡은 프로토콜 스택으로, OSI 7계층 모델보다 실무적이고 간소화된 4계층 구조를 가지고 있습니다.

구조적 특징:

네트워크 액세스 계층 (Network Access): 물리적인 주소(MAC)를 사용해 실제 데이터를 전송하는 계층입니다. (Ethernet 등)

인터넷 계층 (Internet): IP 프로토콜을 사용하여 패킷의 경로를 설정합니다. 통신 노드 간의 IP 패킷 전송을 담당합니다.

전송 계층 (Transport): 프로세스 간 신뢰성 있는 연결을 담당합니다. 신뢰성이 중요한 TCP와 속도가 중요한 UDP가 핵심 프로토콜입니다.

응용 계층 (Application): 사용자와 인터페이스 역할을 하며 HTTP, FTP, DNS 등 서비스별 프로토콜이 존재합니다.

핵심 원리: TCP/IP는 데이터를 작게 나눈 '패킷' 단위로 전송하며, 각 계층을 지날 때마다 필요한 정보(헤더)를 덧붙이는 캡슐화(Encapsulation) 과정을 거쳐 통신이 이루어집니다.
