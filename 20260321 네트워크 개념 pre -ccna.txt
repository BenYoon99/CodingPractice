2. OSI 7 

L1 물리 physical

(랜선과 허브 )

l2 데이터 링크 계층 data link
같은 네트워크 안에서 장치를 식별( 스위치) mac 주소를 사용하며 단위는 프레임 Frame

L3 네트워크 계층 Network
서로 다른 네트워크 간의 최적의 경로를 찾음
router IP 주소를 사용하며 
단위는 packet  패킷

4 주소의 분류

MAC 주소 

physical address
랜카드에 박혀나오는 고유번호
(주민등록번호 생각하기)

IP주소 
Logical Address 
정체 : 네트워크 환경에 따라 할당받는 주소
(집주소라 생각하면됨 
내가 이사하면 주소는 바뀐다)

역할 멀리 떨어진 다른 동네까지 데이터를 보낼때 길찾기용으로 사용함

장비의 차이 Hub vs Switch vs Router

hub L1 
-broadcasting 
data crush 많고 security worst라 잘안씀

switch L2 
MAC 주소표를 보유함

데이터값을 정밀하게 쏴줌 해당 포트로 
같은 네트워크내 서열 1등

router L3

서로 다른 네트워크 연결해주는 장비임 


5. 통신의 방식 3가지

1. 유니캐스트 Unicast 

1 : 1 
특정 대상 한 명에게만 보낸다 (개인 카카오톡)

2. 브로드캐스트 Broadcast 

1: ALL 

같은 네트워크 안의 모든 기기에게 보냄
(아파트 단지 내 방송)

3. Multicast 

1:Group

특정 그룹의 멤버들에게만 전송함
( 단체 카카오톡방)
