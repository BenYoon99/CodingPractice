익명 클래스 

이름이 없는 클래스를 칭함

딱 한번만 쓰고 버릴 임시적 객체 생성에 사용되는 개념

클래스 정의함과 동시에 객체 생성해버림



람다식 (Lambda Expression)

익명 클래스의 이름없음 마저도 귀찮아서 
개발자들이
인터페이스를 받는 익명 클래스 ( 임시)
의 추상메소드 실행시 
사용하는 식임

(매개변수) -> (실행문)
이렇게 형태가 되어있음 


class MyHandler implemnts ActionListener {
	public void actionPerformed(ActionEvent e){
		System.out.println("클릭!");
}
}


메인메소드내  실행

이렇게 진행되지만

우리는 

이걸 


클래스명 (파라미터) -> 실행문 

이렇게 생략해 실행시킬수있음
 

단 언제만?

해당 클래스가
하나의 추상메소드를 가진
함수형 인터페이스를 구현하는 경우에만
그게 가능하다
