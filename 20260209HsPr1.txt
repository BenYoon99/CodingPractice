1. 요구사항

부모 클래스: Unit

변수: String name, int hp

메소드: void move() (출력: "이동합니다")

자식 클래스 1: Marine

move() 오버라이딩: "두 발로 뜁니다" 출력

자식 클래스 2: Medic

move() 오버라이딩: "걸어가서 치료합니다" 출력

// The main method must be in a class named "Main".

class Unit {
    String name;
    int hp;

    void move(){
        System.out.println("이동합니다");
    }
}
class Marine extends Unit {
    @Override 

    void move(){
            System.out.println("두 발로 뜁니다");
    }
}

class Medic extends Unit {
    @Override

    void move(){
        System.out.println("걸어가서 치료합니다");

        
    }
}

/*
2. 메인 함수 미션

Unit[] terran = new Unit[2]; 배열 생성.

0번에는 마린, 1번에는 메딕 객체를 넣고 이름과 체력을 설정하세요.

for문을 돌려 두 유닛의 이름과 move() 결과를 출력하세요.*/
class Main {
    public static void main(String[] args) {
           Unit marine = new Marine();
            marine.name = "marine";  
            marine.hp = 60;

            System.out.println(marine.name);
            Unit medic = new Medic();
            medic.name = "medic";
            medic.hp = 60;
        
        
        Unit [] terran = new Unit[2];
        terran [0] = marine;
        terran [1] = medic;

        int i;
        i=0;
        for(i=0;i<2;i++){
                terran[i].move();
                System.out.println(terran[i].name);
        }
    
    }
}
