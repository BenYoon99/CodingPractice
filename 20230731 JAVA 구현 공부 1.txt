1. char 데이터타입과 String / String 외부클래스



char은 String과 다르게 

문자열이아닌 문자하나만을 다루는 데이터타입이다. 이 데이터타입은 String과의 차이가 

String은 문자열이고 char은 문자하나인것이다.

그리고 String은 java.lang 패키지안에 포함된 내장 클래스라는점이다.

그렇기에 String은 일반적인 다른 데이터타입들과는 결이 다르다.

예시를 보자


String ex1 = "";


이것은 우리가 흔히 알고리즘문제를 풀때 접할수있는 문자열 변수를 파주고 거기에 기본값을 넣어준 모습이다.

근데 이것을 자세히 이해해보자면

String 이라는 java.lang 패키지에 있는 built in class == 내장 클래스를 참조하는 참조변수 ex1을 생성해준후 거기에 "" 기본값을 대입한 모습이다.

참조 --- 객체생성이기에 

우리는 힙영역에 new를 넣어주고 영역을 파고 생성자를 통해 인스턴스 생성을 해야할것같지만

이러한 문자열 리터럴에는 특별한 편의기능을 자바는 제공한다.

바로 new string("");
에서 new 인스턴스명 생성자를 생략해주는 기능이다.

문자열 변수생성시 리터럴값에 ""가 들어간다면

자바는 그 즉시 해당 문자열이 문자열변수임을 인지하고 해당 인스턴스명 생성자를 생략해도 오케이해준다.

이렇게 자바이용시 String 내장클래스에는 다양한 메소드들이 있고 우리는 그것을 참조해서 사용할수있기에 
매우 유용하다.
고로 문자를 다루는 '' char은 서로 간에 1글자씩간의 문자를 주고받는 상황에서도 잘 사용하지않고 String 을 주로 사용한다.

2-6 charSequence  ----- String & StringBuilder

String 과 StringBuilder은 부모인터페이스로 charSequence를 구현받는다
이미 자체적으로 구현이 되어있기에 실코드에서 내가 직접 implements 칠필요없다.

String과 StringBuilder는 그렇게 차시퀀스를 구현받는 자식들로써 형제다

하지만 사용의 용도가 다르다

String은 대다수의 상황 즉 99% 이상의 상황에서 대체적으로 그냥 사용된다

하지만 그 내장 클래스 자체가 갖고있는 한계가 있기에 가끔 StringBuilder을 사용하기도한다.
그 점에대해서 설명해주겠다

String은 immutable 즉 내장 불가변클래스이다.
말이 어렵지만
쉽게 풀자면

동적 정적 오버로딩 오버라이딩 배운것처럼

우리가 어떠한 값을 대입했을경우에 그 값을 수정하지 못하는걸 의미한다.

고로 예시를 들어보자면

String ex1 = "bb";
String ex2 = "aa";
 ex2 = ex1+1;

이경우에 
ex2 에 존재하던 aa값이 bb1로 업데이트된것이아니라
힙영역에 새로운 문자열리터럴값인 aa1값을 새로 생성후
그걸 ex2라는 리모컨으로 조종 즉 덮어씌운것이다.
고로 이런 경우 고도의 반복문이나 이러한 문자열 연산 문자열 대입이 많이일어나는 상황에서 CPU 낭비가 매우 심하게된다
그러한 1%의 상황에

StringBuilder을 사용한다. StringBuilder은 mutable 즉 가변클래스이다.
