🔱 미션: '참조 변수와 메모리 주소' 추적하기
아래 코드를 보고, **메모리(Stack/Heap)**에서 어떤 일이 벌어지는지 분석하고 결과를 도출하십시오.

[코드 스니펫]
Java

class Unit {
    int hp = 100;
}

public class MemoryTest {
    public static void main(String[] args) {
        Unit u1 = new Unit(); // 1번
        Unit u2 = u1;         // 2번
        
        u2.hp = 80;           // 3번
        
        System.out.println("u1의 HP: " + u1.hp); // 출력 A
        System.out.println("u2의 HP: " + u2.hp); // 출력 B
    }
}
[분석 과제]
1번 라인: Stack 영역에는 무엇이 생기고, Heap 영역에는 무엇이 생깁니까?

2번 라인: u2라는 이름표(참조 변수)가 새로 생겼습니다. 이때 u2는 힙에 새로운 객체를 만듭니까, 아니면 기존 u1의 주소값을 복사합니까?

결과 도출: 출력 A와 출력 B에 찍힐 값은 각각 얼마입니까? (힌트: u1과 u2는 같은 집을 보고 있을까요, 다른 집을 보고 있을까요?)




1:    Stack 영역에는 참조변수 u1이 생성되고       Heap영역에는 new로 땅을 파고 그 부분에 Unit클라스의 규격을 따르는 인스턴스가 아무것도 갖지않고 태어납니다 (제네럴 생성자 ) 

<- 정답 


2: 새로운 객체를 만드는게 아니라  , 같은 스택영역에 있는 u1에게서 u1이 갖고있는 이름없는 Unit을 따르는 인스턴스의 주솟값을 대입받음.
