1. 설정복사 및 정보 출력


RAM --> NVRAM copy and save

RAM 출력 show running-config

후 

NVRAM 시작설정 출력 -> show startup-config


2 Router 상태 검사


show version 라우터 OS 부팅시간 하드웨어 사양


show running config  설정값 확인 


show ip route 라우팅 테이블 경로확인

show protocols 라우터 설정 인터페이스 프로토콜 상태확인

show flash 플래시 메모리 ios 파일목록 확인 


3. Router 패스워드설정 5가지


콘솔: line console 0 → password [비밀번호] → login

Aux: line aux 0 → password [비밀번호] → login

VTY: line vty 0 4 → password [비밀번호] → login

Enable (일반): enable password [비밀번호]

Enable (암호화): enable secret [비밀번호]


4. show interface 명령 및 결과 설명
show interface [인터페이스명] 명령은 특정 포트(예: FastEthernet 0/0)의 상세 상태를 보여줍니다.

실행 예시: show interface fastEthernet 0/0

결과 핵심 해석:

Status (첫 번째 줄): "up/up"이면 물리적 연결과 데이터 링크 계층이 모두 정상입니다. "up/down"은 물리적 신호는 있으나 데이터 통신 불가, "down/down"은 케이블 미연결 등을 의미합니다.

Hardware address: 해당 포트의 MAC 주소 확인.

Internet address: 설정된 IP 주소 및 서브넷 마스크 확인.

MTU / Bandwidth / Delay: 인터페이스의 전송 단위(MTU), 대역폭(속도), 지연 시간 정보.

Input/Output rates: 초당 들어오고 나가는 데이터 패킷의 양과 에러 발생률 확인.
