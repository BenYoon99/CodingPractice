// 데이터 베이스 복습 



데이터베이스란

도서관입니다

파일과 DB의 차이는

파일은 메모장이나 엑셀처럼
개별적인것이기에 혼자 사용하기에 좋고

DB는 여러명이 동시에 사용하기 용이합니다
왜냐하면 데이터가 무결성을 가지고있고 (integrity)
그리고 내가 원하는 자료를 그냥 바로 찾아주기 때문입니다.

데이터베이스는 시대에 따라 발전을 해나갖고
현대의 데이터베이스들 대부분은
RDBMS 관계형데이터베이스 입니다

table 테이블  : 엑셀 시트 같은 표 그 자체입니다

column 컬럼 열  제목을 말합니다 자바로 비유하면 필드입니다

Row  로우    실제 데이터 한줄이다 

PK 기본키

한줄 한줄 식별학ㄹ수있는 고유번호 primary key 기본키입니다

SQL Structured Query Language

DB에게 명령하는 전용언어이다

SELECT 데이터 조회
INSERT 데이터 삽입
 UPDATE 데이터 수정
DELETE 데이터 삭제
