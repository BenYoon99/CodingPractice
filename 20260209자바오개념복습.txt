생성자
생성자의 사용의의 

내가 메인메소드에서 인스턴스를 생성하는데
인스턴스값을 선언과 동시에 짓고싶다면
사용한다 

생성자의 구성

class babo{

	string ipName;

	babo(string ipDestination){
		this.ipName = ipDestination;
}


}

public static void main (String [] args){

	babo b = new babo("경북대학교");
		}

위 경우  b라는 참조변수로 조종하는 babo라는 규격을따르는 인스턴스의
	목적지값(ipName)은 시작부터 경북대학교로 설정이 되어 태어나는것이다.


super 

 super() 은 부모의 생성자 호출이다 

super. 메소드명() 은 부모의 메소드 호출이다

고로 
내가 

부모클래스
메소드 1
자녀 1
메소드 1오버라이딩
자녀2

메소드 1오버라이딩
자녀 3
메소드 1 오버라이딩

이경우에 자녀3으로하여금 오버라이딩한 자녀3의 메소드가 아닌
부모의 메소드사용하게끔하려면

super .부모 메소드명()해주면된다
