1. 라우팅(Routing) 개념
네트워크상에서 데이터를 목적지까지 전달하기 위해 최적의 경로를 설정하고 패킷을 전송하는 과정입니다. 라우터는 라우팅 테이블을 참조하여 패킷을 보낼 다음 경로(Next-hop)를 결정합니다.

2. RIP (Routing Information Protocol)
가장 대표적인 거리 벡터(Distance Vector) 라우팅 프로토콜입니다.

특징: 경로 선택 기준으로 '홉 카운트(Hop Count, 거쳐가는 라우터 수)'만 사용합니다. 최대 15홉까지만 지원하며, 30초마다 전체 라우팅 테이블을 이웃 라우터와 교환합니다.

3. OSPF (Open Shortest Path First)
링크 상태(Link State) 라우팅 프로토콜입니다.

특징: 다익스트라(Dijkstra) 알고리즘을 사용하여 최단 경로를 계산합니다. 대규모 네트워크에 적합하며, 네트워크의 상태 변화(링크 변경 등)가 발생할 때만 변경 정보를 전송하여 효율적입니다.

4. BGP (Border Gateway Protocol)
서로 다른 자율 시스템(AS, Autonomous System) 간에 라우팅 정보를 교환하기 위한 경로 벡터(Path Vector) 프로토콜입니다.

특징: 인터넷 전체의 라우팅을 담당하는 핵심 프로토콜로, 경로의 거리보다는 정책(Policy)과 경로의 안정성을 중시합니다.

5. 경로 결정 요소
라우터가 경로를 결정할 때 고려하는 주요 기준입니다.

Metric: 경로의 비용(속도, 홉 수, 지연 시간 등).

Administrative Distance (AD): 여러 경로가 있을 때 어떤 프로토콜의 경로를 우선할지 결정하는 신뢰도 값.

Next-hop IP: 패킷을 넘겨줄 다음 라우터의 주소.

6. 거리 벡터 라우팅 알고리즘 (Distance Vector)
개념: 인접한 라우터로부터 전체 라우팅 테이블을 주기적으로 전달받아 경로를 계산하는 방식(Bellman-Ford 알고리즘 기반).

장단점: 구현이 단순하나, 네트워크 규모가 커지면 수렴 속도가 느리고 라우팅 루프(Loop) 문제가 발생하기 쉽습니다.

7. 링크 상태 라우팅 알고리즘 (Link State)
개념: 라우터가 네트워크 전체의 토폴로지 정보를 직접 파악하고, 각 링크의 상태 정보를 주변에 전달하여 자신만의 최단 경로 지도를 그리는 방식.

장단점: 네트워크 상태 변화에 빠르게 반응하고 정확한 경로 계산이 가능하나, 라우터가 많은 연산 자원과 메모리를 사용합니다.
