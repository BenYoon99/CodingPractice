//자바 배운내용 복습

자바는 

객체지향언어임

객체지향언어란

사물의 행동이 아닌 사물과 사물간의 관계에 집중하는 언어로
현재 우리세상에서 살아가는 삶에서의 상호작용에 가장 가깝다

자바에서는 

클래스라는 껍데기를 사용해
다양한 인스턴스의 구조를 미리 만들어줄수있다
고로 다수의 인스턴스 생성시에 매우 용이하다
그리고 그런 클래스간에 관계는 매우 복잡하다.

예를들어 
A클래스 B 클래스 C클래스가 있고

이 모든 클래스가 짖기와 이동하기라는걸 갖고 있는 클래스라면
 우리는 이 모든 클래스들에게 해당 클래스 필드에 일일이 
짖기와 이동하기 메소드를 적어줄것이아니라

각각의 메소드들을 이미 틀로써 갖고있는 
부모 클래스 D를 제작하여 

부모클래스로 하여금 부모의 모든 메소드구조들을 그대로 상속해줄수있다
하지만 이 경우 오버라이딩의 강제성이 없기에
만약 a b c 가 모두 다르게 짖는 다고 가정하면 
그렇게 강제해야하는것이다 
고로 그렇게되면 우리는  인터페이스를 생성하여
인터페이스내에 필드에
추상메소드 짖기와 이동하기를 파주면 되는것이다
그렇게되면

형식이 

class D {

abstract void bark({};

abstract void move() { } ;
} 이렇게 내용을 안만들어주면되는것이다.

이렇게 매우 용이하다.

자바는 JVM이라는 자바 버츄얼 머신을 사용하고

자바 버츄얼 머신위에서 동작한다.
고로 하나의 안전장치가 존재한다고 보면된다.
