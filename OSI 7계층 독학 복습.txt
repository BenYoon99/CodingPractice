L6 표현 계층

역할 데이터의 형식 ( 확장자)을 정하고 압축 암호화함

상대방이 알아볼 수 있는 공통 언어로 번역하는 장소이다.

EX) 메시지를 암호화하거나 사진을 JPEG으로 압축하는 과정

L5 세션 계층 

역할 통신하는 양쪽 컴퓨터간 연결을 만들고 유지하고 끊는놈이다.

대화의 시작이자 끝을 관리하는 관리자이다.

EX) 로그인을 유지하고 통신 도중에 끊겼다면 복구 지점을 설정한다.

L4 전송 계층

역할 데이터 전송의 신뢰성을 보장한다 TCP UDP등장하는 계층

데이터가 잘 도착했는지 확인하며 순서대로 조립하는 곳이다.

L3 네트워크 계층

역할 가장 빠른 길을 찾음 (라우팅) IP 주소가 여기서 사용된다.

목적지까지 어떤 경로로 갈지 지도를 그리는 곳

이 계층에서 핵심적으로 사용되는 장비는 라우터이다.

EX) 택배 트럭이 서울에서 부산까지 가게 된다면
어떠한 고속도로를 탈지 국도를 탈지 결정하는 절차.

L2 데이터 링크 계층

역할 인접한 장치 간의 물리적인 연결을 관리.
MAC 주소를 사용한다.

직접 연결된 옆집 장비와 데이터를 주고 받는 통로

이 계층에서의 핵심 장비는 Switch이다.

 EX) 고속도로 톨게이트를 지날 때마다 앞차와의 간격을 조절하고 안전하게 지나가는 것.

L1 물리 계층 

역할 데이터를 0과 1의 전기 신호(비트)로 바꾸어서 실제 구리선이나 광섬유로 씀.
