자바의 다형성

자바의 다형성이란 부모타입의 참조변수로 다양한 타입의 인스턴스를 조종하는걸 말한다.
부모의 클래스의 참조변수로 인스턴스 조종하는걸로 통일하여서 한번에 다같이 배열이나 ArrayList
에 넣어서 관리한다.
그렇게 해서 용이하게 method를 한번에 다같이 시행시킬수있다.



for문 

for ( 초기식 조건식 증감식) {
실행문
}



enhanced loop for 문

for ( 자료형타입 이름표 : 배열 or ArrayList명) 
{   이름표 .메소드      실행문}






class Parent {
    int x = 10;
    void show() {
        System.out.println("Parent Show");
    }
}

class Child extends Parent {
    int x = 20; // 변수 중복 선언
    @Override
    void show() {
        System.out.println("Child Show");
    }
    void childSpecial() {
        System.out.println("Child Only");
    }
}

public class PolyTest {
    public static void main(String[] args) {
        Parent p = new Child(); // 다형적 참조 (업캐스팅)
        
        System.out.println("Value of x: " + p.x);
        p.show();
        
        // p.childSpecial(); // 이 줄의 주석을 풀면 어떻게 될까요?
    }
}
